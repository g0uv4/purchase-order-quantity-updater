採購單數量與金額調整工具－使用說明
==================================

用途
----
依出貨清單更新採購單中的數量、未稅金額與採購金額合計。

- 原始採購單不會被覆寫。
- 資料只在本機處理，不會上傳到網路。
- 只有「採購單號＋項次＋料號」完全相同的項目才會更新。

開始前
------
1. 將下載的 ZIP 完整解壓縮。
2. 準備一份採購單檔案（內容為 HTML 的 .xls）。
3. 依「出貨清單_範本.xlsx」填入實際出貨數量。

操作步驟
--------
1. 雙擊「採購單數量與金額調整工具.exe」。
2. 在「採購單檔案」選擇要處理的 .xls。
3. 在「出貨清單」選擇已填妥的 .xlsx 或 .csv。
4. 確認畫面上的兩個檔名後，按「開始處理」。
5. 完成後，可直接開啟結果檔或結果所在資料夾。

處理規則
--------
1. 採購單號、項次與料號必須完全相同才會修改。
2. 出貨清單未列出的項目保留原值，不會改成 0。
3. 料號不符、資料重複或無法解析時，該項目保留原值並寫入紀錄。
4. 已修改項目的未稅金額會依「出貨數量 × 單價」重算。
5. 採購金額合計只套用已修改項目的差額。

出貨清單格式
------------
第一列需包含以下四個欄位：

| 採購單號     | 項次 | 料號         | 出貨數量 |
| PO-DEMO-001 | 1    | ITEM-DEMO-A | 100      |
| PO-DEMO-001 | 2    | ITEM-DEMO-B | 250      |

- 採購單號與料號是識別文字，請保留原有格式。
- 項次必須是正整數。
- 出貨數量不得為負數。

輸出檔案
--------
結果會儲存在原始採購單所在資料夾：

- 結果檔：原檔名_出貨調整_日期時間.xls
- 詳細紀錄：原檔名_出貨調整_日期時間.log.txt

常見狀況
--------
- 顯示「沒有有效資料」：請檢查出貨清單欄位名稱與內容。
- 顯示「料號不符」：請確認出貨清單料號與採購單完全相同。
- 顯示「找不到完全相同的採購單號＋項次」：該列不會修改，請核對兩份檔案。
- Excel 開啟結果檔時若提示格式與副檔名不一致，可確認開啟；此類 .xls 實際上是 HTML 表格。

給維護人員
----------
原始碼仍可用命令列執行：

    python 採購單大量修改數量與總價.py "採購單.xls" "出貨清單.xlsx"

讀取 .xlsx 需要 openpyxl；一般使用者執行 .exe 不需安裝 Python 或套件。
