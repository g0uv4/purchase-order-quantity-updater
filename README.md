# 採購單數量與金額調整工具

一個離線 Windows 工具，依出貨清單更新 HTML 格式採購單中的數量、未稅金額與採購金額合計。

## 下載

請從 [Releases](../../releases/latest) 下載最新的 Windows ZIP，完整解壓縮後執行：

`採購單數量與金額調整工具.exe`

一般使用者不需要安裝 Python。

## 使用方式

1. 選擇內容為 HTML 的 `.xls` 採購單。
2. 選擇依 `出貨清單_範本.xlsx` 填寫的 `.xlsx` 或 `.csv`。
3. 按下「開始處理」。
4. 完成後開啟結果檔或詳細紀錄。

結果會另存於原始採購單所在資料夾，不會覆寫原檔。

## 處理規則

- 採購單號、項次與料號必須完全相同才會更新。
- 出貨清單未列出的項目保留原值，不會改成 0。
- 料號不符、資料重複或無法解析時，該項目保留原值並寫入紀錄。
- 未稅金額依「出貨數量 × 單價」重算。
- 採購金額合計只套用已修改項目的差額。

## 隱私

- 程式不含遙測、網路請求或雲端上傳功能。
- 採購單、出貨清單、結果與紀錄都只在使用者電腦上處理。
- 儲存庫與發布檔僅包含虛構範例，不含實際採購單號、料號或內部路徑。

## 從原始碼執行

```powershell
python -m pip install openpyxl==3.1.5
python .\採購單大量修改數量與總價.py
```

也可直接指定兩個檔案：

```powershell
python .\採購單大量修改數量與總價.py "採購單.xls" "出貨清單.xlsx"
```

## 建置 Windows 執行檔

需要 Python 3.12 或相容版本：

```powershell
.\build.ps1 -Python python -Version v1.0.0
```

建置結果會輸出至 `dist`，包含單一 `.exe` 與可發布的 ZIP。

## 驗證

